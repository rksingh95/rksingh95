## 👋 About

I build and lead engineering teams that ship reliable, scalable software for logistics and automation. I started as a backend developer, moved through machine learning research and cloud infrastructure, and now lead teams while staying hands-on with architecture and applied AI.

I like systems that are simple to operate, observable in production and honest about their limits. For AI, that means agents with clear boundaries, evaluation loops and a human in charge when confidence is low.

- 🏗️ Designing distributed, event-driven backends and the platforms they run on
- 🤖 Building agentic AI workflows: plan, execute, evaluate, improve
- ☁️ Cloud-native infrastructure as code on Google Cloud and Kubernetes
- 👥 Growing engineers through mentoring, hiring and clear technical direction
- 🎓 M.Sc. Mechatronics (machine and deep learning focus), Universität Siegen
